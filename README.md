# Agile Travel – QA Testing Project

## Project Overview

This project demonstrates exploratory and functional testing performed on the Agile Travel website.

The main objective was to explore the flight booking flow, identify reproducible defects, and document them clearly using Jira.

## Website Under Test

https://travel.agileway.net/login

## Testing Approach

* Exploratory Testing
* Functional Testing
* Negative Testing
* Input Validation Testing
* Defect Reproduction

## Tools

* Jira
* Google Chrome
* GitHub

## Testing Scope

The following areas were explored:

* Login
* Flight Search
* Flight Date Selection
* Passenger Information
* Payment
* Booking Confirmation

## Defects Identified

A total of **7 reproducible defects** were identified during exploratory testing.

| ID      | Defect                                                | Severity | Priority |
| ------- | ----------------------------------------------------- | -------- | -------- |
| BUG-001 | Same departure and arrival city accepted              | Medium   | Medium   |
| BUG-002 | Past departure date accepted                          | Medium   | Medium   |
| BUG-003 | Return date earlier than departure accepted           | Medium   | High     |
| BUG-004 | Invalid passenger name characters accepted            | Medium   | Medium   |
| BUG-005 | Booking completed with incomplete payment information | High     | High     |
| BUG-006 | Expired card accepted                                 | High     | High     |
| BUG-007 | Invalid card number accepted                          | High     | High     |

## Jira

The defects were also documented in Jira as part of the QA project.

**Jira Project:** Agile Travel QA (SCRUM)
