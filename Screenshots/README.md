# Screenshots

This folder contains screenshots captured during exploratory testing of the Agile Travel website.

Each screenshot provides supporting evidence for the corresponding defect documented in the `Bug-Reports` folder.

## Evidence

Screenshots will be organized according to their corresponding bug ID:

* BUG-001 – Same Departure and Arrival City
* BUG-002 – Past Departure Date
* BUG-003 – Invalid Return Date
* BUG-004 – Invalid Passenger Name
* BUG-005 – Incomplete Payment Information
* BUG-006 – Expired Card
* BUG-007 – Invalid Card Number
